- 「実際の現場の課題の解決に取り組み、成果を出しているか」
- 「個人の改善ではなく、チームや組織の変革になっているか(繋がっているか)」
- 「AIで現行業務を改善したのではなく、前提を壊して、あるべき姿をAI前提で描き、業務フローごと変革しているか」

## 応募案

1. **年1回のセキュリティチェックを、AIで継続的に監視するようにする**
2. **脆弱性が発表されたときの対応フローをAIで代替**

## 応募フォームの設問（Q1〜Q14）

※提供された応募フォームのスクリーンショット（ページ2/3）から転記。Q1〜Q13は必須、Q14は任意。選択肢は未選択の状態で記載。

### Q1. この取り組みは、いまどの段階にありますか？（単一選択・必須）

- 構想段階（検証・開発はこれから）
- PoC・検証中（試作や限定的なテストを実施中）
- 実務で試行中（実際の業務の一部で利用中）
- 実務展開済み（業務の一部として継続的に利用中）
- 他部署・他拠点へ展開中

### Q2. 対象業務は、次のどれに最も近いですか？（単一選択・必須）

- 中核業務（製品・サービス、品質、安全、お客様、売上に直接関わる業務）
- 支援業務（計画、分析、調整など、中核業務を支える業務）
- 周辺業務（定型的な事務作業など）

### Q3. AIにより対象業務はどう変わりましたか？（複数選択・必須）

当てはまるものをすべて選択。選んだ変化はQ4で具体的に説明する。

- 対象の工程をなくした
- 複数の工程を統合した
- 対象業務の順序・流れを変えた
- これまでになかった成果物・サービスを生み出した
- 人の役割や、判断の担い方を変えた
- 生まれた時間を別の業務に振り向けた
- これまでの作業をAIで代替した（工程は変えていない）
- その他

### Q4. 対象業務の変化を詳細に教えてください。（自由記述・必須、4000文字以内）

Q3で選んだ変化が伝わるように、以下を含め箇条書きで記載する。

1. 改善前の業務
2. 改善前の業務の課題
3. 改善後の業務
4. 改善後の業務において、AIが担う部分は何か
5. 改善後の業務において、人が担う部分、将来的にも残すべき部分は何か
6. 改善による創出時間・費用の振り向け先

### Q5. Q4で記した改善に至るまでの経緯を教えてください。（自由記述・必須、4000文字以内）

現在の改善策にたどり着き、実現するまでの経緯（思考やアクション）を書く。未実施の場合は計画を記載する。

1. 経緯
2. (1)で書かれた経緯の内、主にAIが行ったこと
3. (1)で書かれた経緯の内、主に人間が行ったこと

### Q6. これまでに実際に得られた成果のうち、いちばん大きなものはどれですか？（単一選択・必須）

今後見込まれる成果はQ10とQ11で説明する。

- 時間・工数の削減
- リードタイムの短縮
- 品質向上・エラー削減
- 売上・受注の増加
- コスト削減
- 安全・コンプライアンス・リスクの低減
- お客様への価値の向上
- 研究開発のスピード・成功率の向上
- 新たにできるようになったこと
- まだ成果は出ていない
- その他

### Q7. Q6の成果は、どのように確認しましたか？（単一選択・必須）

いちばん確かな方法を1つ選択する。

- システムのログ・記録
- 一定期間の実測
- 利用者へのアンケート
- 担当者による推計
- まだ確認していない／成果はまだ出ていない
- その他

### Q8. 類似する業務や課題があり、この取り組みを広げられそうな領域はどこですか？（単一選択・必須）

水平展開による最も価値を生むと考えるものを選択する。

- 自部署内のみ
- 同じ国内の他部署・他拠点
- 他リージョンを含むグループ全体
- 社外（お客様・取引先）にも提供できる
- その他

### Q9. 年間の効果額と投入コストについて、当てはまる金額帯を選んでください。（行ごとに単一選択・必須）

金額の大きさだけで評価することはない。**1 USD＝150円**として回答する。

**金額帯（各行共通）**

- なし・算出できない
- 100万円未満
- 100万〜1,000万円未満
- 1,000万〜1億円未満
- 1億〜10億円未満
- 10億〜100億円未満
- 100億円以上

**回答対象の3項目**

| 項目 | 選択する内容 |
| --- | --- |
| 実現済みの年間効果額 | 上記金額帯から1つ |
| 今後3年以内に見込まれる年間効果額（実現済みの年間効果額を除く） | 上記金額帯から1つ |
| 投入コスト（初期費用＋年間費用。工数は標準単価で換算） | 上記金額帯から1つ |

### Q10. Q6〜Q9で選択した内容の裏付けを教えてください。（自由記述・必須、4000文字以内）

概算でよい。以下を含めて箇条書きで記載する。構想段階の場合、実現済みの年間効果額と成果指標は空欄でもよい。金額計算の際は標準単価を記載し、円またはUSDで示す。為替の影響がある場合は換算方法も記載する。**1 USD＝150円**とする。

1. 実現済みの年間効果額（Before/After）と根拠（計算方法、測定期間）
2. 今後見込まれる年間効果額と根拠（計算方法）
3. 投入コスト（開発工数、運用工数、ツール・外注費など）※初期コストと運用コストを分けて記載
4. 金額に換算できない価値と根拠
5. Q8の水平展開候補の詳細、展開時の制約条件

### Q11. 改善業務を継続的に運用するための取り組み状況を選んでください。（行ごとに単一選択・必須）

それぞれの項目に対し、**「実施中・活用中」「計画中」「該当なし」**のいずれかを選ぶ。

| 取り組み項目 | 回答欄 |
| --- | --- |
| AIの動きを確認する手順を設け、誤りやリスクが見つかった場合に対応する | 実施中・活用中／計画中／該当なし |
| 運用責任者と担当体制を決め、引き継ぎ後も運用が途切れないようにする | 実施中・活用中／計画中／該当なし |
| 業務手順や判断理由、意思決定理由を記録し、知見を社内に残す。必要な人が後から確認できるようにする | 実施中・活用中／計画中／該当なし |
| 利用者意見等を元に、AIに与えるデータや指示・ルールを定期的に見直す | 実施中・活用中／計画中／該当なし |
| 現場で培われた知識や経験を、AIの使い方や業務の進め方に取り入れる | 実施中・活用中／計画中／該当なし |
| その他 | 実施中・活用中／計画中／該当なし |

### Q12. Q11の各項目について、どのように取り組んでいるか、あなたの考えを教えてください。（自由記述・必須、4000文字以内）

具体的に書いた項目が評価につながる。すべて「該当なし」の場合は「なし」と記入する。

### Q13. 応募内容において、AIが一般化した世界でも残る富士フイルムならではの強みは何だと思いますか？（自由記述・必須、4000文字以内）

利用した知識・データ・技術・関係性等だけでなく、それが差別化にどうつながるかを具体的に書く。
